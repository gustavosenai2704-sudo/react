## 📌 Sobre o projeto

O **NewsPulse** é um aplicativo mobile desenvolvido com **React Native + Expo**, que permite aos usuários acompanhar **notícias em tempo real** 🌍 e consultar **informações climáticas atualizadas** 🌦️ de qualquer lugar do mundo.

A aplicação foi criada com foco em **consumo de APIs**, **autenticação de usuários** e **experiência fluida**, sendo ideal para estudantes que desejam acesso rápido a informações importantes no dia a dia.
